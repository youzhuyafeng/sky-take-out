JavaWeb苍穹外卖练习项目（仅后端）

2026.5.6开始，2026.5.21结项，计15天

作为练手项目，除了java基础语法和库之外，主要用于熟悉一些第三方的javaAPI和Mybatis作为半自动的ORM框架的在操作时一些细节问题，“纸上得来终觉浅”，听课跟上手写代码是两回事，至少对于我来说大部分Debug的时间基本都用于与Mybatis斗智斗勇了（笑）。

该项目大部分代码属于基础的CRUD功能，少量涉及WebSocket、Spring Task、AOP、Redis技术，整体难度不大。于我而言其实该项目的最大收获其实是终于对git命令体系比较熟悉了，之前基本只会git add . git commit git push git pull 几个简单的命令，写这个项目时遇到的一些问题让我不得不深入了解一下git怎么用。

碎碎念就到这了。总之作为第一个项目还是让我收获颇丰😊
